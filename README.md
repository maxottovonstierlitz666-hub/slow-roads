# Slow Roads — бесконечная процедурная дорога

Мини-игра в духе [Slow Roads](https://slowroads.io): спокойная езда по бесконечно генерируемой дороге.
Никакого финиша и соперников — только дорога, холмы и вид.

Всё в одном файле `index.html`: HTML, CSS и JavaScript. Ни сборки, ни зависимостей —
three.js подгружается с CDN.

## Как запустить

**Вариант 1 — сразу, без настройки:**
открыть через htmlpreview:
`https://htmlpreview.github.io/?https://github.com/maxottovonstierlitz666-hub/slow-roads/blob/main/index.html`

**Вариант 2 — свой адрес через GitHub Pages:**

1. Settings → Pages
2. Branch: `main`, папка `/ (root)` → Save
3. Игра будет по адресу `https://maxottovonstierlitz666-hub.github.io/slow-roads/`

**Вариант 3 — локально:** скачать `index.html` и открыть в браузере.

Нужен интернет при открытии (three.js грузится с unpkg) и поддержка WebGL.

## Что внутри

- **Процедурная дорога.** Осевая линия строится по сумме трёх синусов: кривизна и высота
  зависят от пройденного расстояния `s`. Точки добавляются впереди и удаляются позади —
  дорога бесконечна, а память не растёт.
- **Лента полотна.** Из точек строится треугольная полоса с UV вдоль `s`, поэтому разметка
  (края + прерывистый центр) рисуется процедурной текстурой на canvas.
- **Ландшафт.** Широкая сетка вдоль дороги: у самого полотна плоско, дальше — холмы
  (функция от расстояния до дороги и `s`). Плоское затенение даёт низкополигональный вид.
- **Деревья.** Детерминированный хеш от номера «слота» вдоль дороги — расстановка стабильна,
  ничего не мерцает при пересборке. Рисуются через `InstancedMesh` двумя вызовами.
- **Машина.** Набор простых боксов; положение — точка на осевой линии плюс поперечное
  смещение, наклон по уклону дороги, крен в повороте.
- **Три времени суток** — день, закат, ночь: меняются цвета неба (шейдер), тумана и света.

## Ограничения

- Это не полноценная физика: машина едет «по дороге», а не по свободному миру.
- Нет звука и сохранений.
- На слабых телефонах возможны просадки — уменьши масштаб страницы или закрой другие вкладки.
